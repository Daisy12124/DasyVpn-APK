# DASY VPN

اپلیکیشن VPN برای اندروید با رابط کاربری فارسی، ساخته‌شده با موتور **Xray-core** (همان هسته v2rayNG).

## امکانات

- پشتیبانی از پروتکل‌های **VLESS** (با Reality و TLS)، **VMess**، **Trojan** و **Shadowsocks**
- **دریافت کانفیگ رایگان** از فهرست‌های عمومی GitHub (بدون نیاز به VPS)
- افزودن سرور با لینک، یا **لینک اشتراک** (subscription)
- بایپس ترافیک داخلی ایران
- اتصال از اپ‌های انتخابی (per-app VPN)
- نمایش سرعت آپلود/دانلود و مدت زمان اتصال
- تست تأخیر سرورها
- اتصال خودکار پس از ریستارت (Always-on از تنظیمات اندروید)

## چطور بسازم و روی گوشی نصب کنم؟

### نیازمندی‌ها

1. کامپیوتر ویندوز/لینوکس/مک با حداقل ۸ گیگ رم
2. نصب **Android Studio** (رایگان): <https://developer.android.com/studio>
3. یک گوشی اندروید با فعال بودن **USB Debugging** (تنظیمات → گزینه‌های توسعه‌دهنده)

### مراحل

1. Android Studio را باز کنید → **Open** → پوشه `DasyVpn` را انتخاب کنید
2. صبر کنید تا Gradle تمام وابستگی‌ها را دانلود و هماهنگ کند (بار اول چند دقیقه طول می‌کشد)
3. گوشی را با کابل به کامپیوتر وصل کنید و USB Debugging را تأیید کنید
4. از نوار بالا گوشی‌تان را انتخاب کنید و دکمه ▶️ (Run) را بزنید
5. اپ روی گوشی نصب و اجرا می‌شود

### ساخت فایل APK برای نصب دستی

1. منوی **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
2. فایل ساخته‌شده اینجاست:
   `app/build/outputs/apk/debug/app-debug.apk`
3. همین فایل را روی گوشی کپی و نصب کنید (نصب از منابع ناشناخته را فعال کنید)

## نحوه استفاده

1. اپ را باز کنید → به تب **سرورها** بروید
2. **بدون VPS:** دکمه **«دریافت کانفیگ رایگان»** را بزنید — اپ از چند فهرست عمومی GitHub کانفیگ می‌گیرد
3. یا دکمه **+** را بزنید و لینک سرور خود را بچسبانید (`vless://`، `vmess://`، `trojan://`، `ss://`)
4. یا اگر **لینک اشتراک** خریداری‌شده دارید، از دکمه دانلود (⬇️) استفاده کنید
5. یک سرور را انتخاب کنید و از تب **خانه** دکمه روشن/خاموش را بزنید

> **درباره کانفیگ‌های رایگان:** سرورها متعلق به افراد ناشناس هستند؛ برای وب‌گردی معمولی قابل استفاده‌اند ولی برای کارهای حساس بهتر است VPS شخصی یا اشتراک معتبر بخرید. سرورهای رایگان معمولاً شلوغ و کندند — اگر وصل نشد، سرور دیگری را امتحان کنید یا روی همان سرور «تست» (⏱) بزنید.

## نکات فنی

- هسته: کتابخانه رسمی [libv2ray](https://github.com/2dust/AndroidLibXrayLite) از سازنده v2rayNG
- رابط هسته با VpnService دقیقاً مطابق الگوی v2rayNG پیاده‌سازی شده (TUN داخلی Xray)
- DNS از DoH (dns.google) از داخل تونل عبور می‌کند تا آلودگی DNS دور زده شود
- فایل‌های geoip/geosite همراه AAR هسته می‌آیند

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| Gradle خطا دارد | اینترنت را چک کنید؛ Android Studio را به‌روز کنید |
| «مجوز VPN لازم است» | دیالوگ اندروید را تأیید کنید |
| وصل نمی‌شود | لینک سرور را در اپ v2rayNG هم تست کنید؛ به تب «گزارش» نگاه کنید |
| سرعت کم | سرور دیگری از اشتراک را انتخاب کنید؛ پروتکل Reality معمولاً سریع‌تر است |
